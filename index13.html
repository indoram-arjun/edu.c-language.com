Structure

Structure :-

➡️ Structure ek user-defined data type hai jo alag-alag data types ke variables ko ek group me store karne ke liye use hota hai.

➡️ Aap ise real-life form ke jaise samajh sakte ho — jaise Student ka naam, roll no, aur marks alag-alag type ke data hote hain, lekin sab ek hi student ke hote hain.

➡️ Structure ka use hum tab karte hain jab ek hi type ke data ka group banana ho (jaise ek student ke sabhi details ek jagah rakhna).

Example :-

  • #include stdio.h
  • // Structure declaration (Ye ek structure declaration hai jiska naam hai Student.
  • struct Student
  • {
  • int rollNo;//Isme 3 Members hain int,char,float
  • char name[50];
  • float marks;
  • }
  • int main()
  • {
  • struct Student s1; // Is variable ke through hum ek student ke data ko access karenge.
  • // Taking input
  • printf("Enter Roll No: ");
  • scanf("%d", &s1.rollNo);
  • printf("Enter Name: ");
  • scanf("%s", &s1.name);
  • printf("Enter Marks: ");
  • scanf("%f", &s1.marks);
  • // Display output
  • printf("\n\nStudent Details:\n");
  • printf("Roll No: %d\n", s1.rollNo);
  • printf("Name: %s\n", s1.name);
  • printf("Marks: %f\n", s1.marks);
  • return 0;
  • }
