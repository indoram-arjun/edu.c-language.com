Loop in C

What is Loop?

▶️ Any repeated task performed more than once is called a Loop.

➡️ For Loop (No of Iteration)

For loop executes the statements of the program several times repeatedly until a given condition returns false.

#include stdio.h

int main ()

{

int num, i

printf(“Enter table);

scanf(“%d”, &num);

for (i=1; i<=10; i++)

{

printf(“%d * %d : %d\n”, num, i, (num*i));

}

return 0;

}

➡️ While Loop

A while loop is a control flow statement that repeatedly executes a block of code as long as a specified condition remains true. It checks the condition before each iteration, making it ideal for running code an unknown number of times until a certain requirement is met.

#include stdio.h

int main ()

{

int num, i=1;

printf(“Enter table);

scanf(“%d”, &num);

while

{

printf(“%d * %d : %d\n”, num, i, (num*i));

}

return 0;

}

➡️ Do While Loop

A Do While Loop is similar to While loop,but it guarantees that the loop body execute at least once, because the condition is checked after the body.

#include stdio.h

int main ()

{

int num, i=1;

do

{

printf("%d\n", i);

i++;

}
