Conditional statements

Conditional statements :-

▶️ Conditional statements in C are used to make decisions in a program. They allow the program to choose which block of code to execute based on whether a condition is true or false.

If Statement

➡️ Execute a block of code only if the condition is True.

Example :-

  • int x=10;
  • if(x>5)
  • {
  • printf("X is greater than 5");
  • }

If-else Statement

➡️ If condition is True → execute the block, otherwise execute else block.

Example :-

  • int x=3;
  • if(x%2==0)
  • {
  • printf("Even");
  • }
  • else
  • {
  • printf("Odd");
  • }

If-else If Ladder

➡️ Used when multiple condition need to be checked sequentially.

Example :-

  • int marks=75;
  • if(marks>=90)
  • {
  • printf("A");
  • }
  • else if(marks>=60)
  • {
  • printf("B");
  • }
  • else
  • {
  • printf("C");
  • }

Nested If

➡️ An If inside another If. Used for multiple level checking.

Example :-

  • int a=10, b=20;
  • if(a>0)
  • {
  • if(b>0)
  • {
  • printf("Both Positive");
  • }
  • }

Switch Statement

➡️ Selects one block of code to execute from multiple choices bbased on a value.

Example :-

  • int ch=2;
  • switch(ch)
  • {
  • case 1:
  • printf("One");
  • break;
  • case 2:
  • printf("Two");
  • break;
  • default:
  • printf("Invalid");
  • }
