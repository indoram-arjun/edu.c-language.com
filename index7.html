Array in C

What is Array?

  • ◆ An array is a way to take multiple values by using single identifiers/variables.
  • ◆ An Array is a group or collection of the same data types.
  • ◆ Collection of similar data types. That’s called Array.
Array in C: Example

#include stdio.h

int main ()

{

int numbers [4] = {22,29,72,27};

printf(“%d\n”, numbers[0]);

printf(“%d\n”, numbers[2]);

printf(“%d”, numbers[3]);

return 0;

}

Output

22

72

27

int numbers [4] = {22,29,72,27};

Index 0 Index 1 Index 2 Index 3
22 29 72 27
To Call Data by Index Value –

printf(“%d”, numbers[0]);
