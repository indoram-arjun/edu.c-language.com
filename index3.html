Variable

What is Variable?

  • A Variable is a container that can store a ‘Value’. It cannot start with a digit.
  • A Variable is a name of memory location. A Variable can start with the alphabet.
  • Variables are names for the storage location to store values.
  • In programming a variable is a container (Storage Area) to hold data. This is also called Variables.

For Example:

  • a=3;   //a is assigned “3”
  • b=4.7;  //b is assigned “4.7”
  • c=’A’;  //c is assigned “A”
