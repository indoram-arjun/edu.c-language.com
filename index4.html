Operators

What are Operators?

  • Operator is a symbol used to perform mathematics or logical operations on Variables and values.
  • An operator is a symbol that operates on a value or a variable. For example, + is an operator to perform addition.
  • C has a wide range of operators to perform various operations.

Arithmetic Operator

An arithmetic operator performs mathematical operations such as addition, subtraction, multiplication, division, etc., on numerical values (constants and variables).

#include stdio.h

int main ()

{

int a, b,c;

printf(“Enter a,b”);

scanf(“%d”, &a,&b);

c=a+b

printf ("Sum : %d",c);

}

Assignment Operator

  • The assignment operator (=) in C is a special operaotr used to assign value of the right-hand side expression to the left-hand side variable.
  • In Short:- Assignment operator stores the computed value of the right-hand side into the variable on the left-hand side.

#include stdio.h

int main ()

{

int a, b;

printf(“Enter a,b”);

scanf(“%d”, &a,&b);

a+=b;

printf ("Sum : %d",a);

}

Relational Operator

Relational operators are used to compare two values in the C language. It checks the relationship between two values. If the relation is true, it returns 1. However, if the relation is false, it returns 0.

#include stdio.h

int main ()

{

int a=10, b=20;

printf (“Enter Value of A: %d”, a);

printf (“Enter Value of B: %d”, b);

if(a==b)

{

printf(“True”);

}

else

{

printf(“False”);

}

}

Logical Operator

Logical operators in C are used to combine multiple conditions/constraints. Logical Operators return either 0 or 1, it depends on whether the expression result is true or false. In C programming for decision-making, we use logical operators.

➡️ Logical AND Operator:-

If both operands are non-zero then the condition becomes true. Otherwise, the result has a value of 0. The return type of the result is int. Below is the truth table for the logical AND operator.

For Example: 1 – True, 0 - False

1 0 0
0 1 0
0 0 0

scanf(“%d”, &b);

if((a==b) && (a>=b))

{

}

else

{

printf(“False”);

}

}

#include stdio.h

int main ()
