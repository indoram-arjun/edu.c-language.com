Control Statements

Go to Statement in C

  • The Goto statement is a jump statement. It is used to transfer the program control from one location to another location.
  • It is used to transfer the program control from one statement to another statement (Where Label is Defined).
  • The Goto statement is known as a Jump Statement in C.
  • Especially, Goto statements use two terms.
    1. ◆ To Create a Loop.
    2. ◆ To Break a Loop.

Notes: -

Goto Statement Label ki help se jump Karta H.

#include stdio.h

int main ()

{

int num, i=1;

printf(“Enter Number”);

scanf(“%d”, &num);

table:

printf(“%d * %d = %d\n”, num, i, (num*i));

i++;

if(i<=10)

goto table;

return 0;

}

Switch Statement in C

In C, the switch statement is a multi-way branch statement that allows a variable to be tested against a list of values (cases), and executes the block of code corresponding to the matching case.

Notes: -

Ek case execute hone ke baad baaki cases execute nahi hote.

#include stdio.h

int main ()

{

int i=4

switch(i)

{

case1:

printf("One");

break;

case2:

printf("Two\n");

break;

case3:

printf("Three\n");

break;

case4:

printf("Four\n");

break;

}

}

Break Statement in C

The break statement in C is used to immediately terminate the execution of the current loop (for, while, do-while) or a switch statement, and transfer the control to the statement immediately after that loop or switch.

Notes: -

loop/switch पूरी तरह terminate कर देता है।

#include stdio.h

int main ()

{

int i=4

switch(i)

{

case1:

printf("One");

break;

case2:

printf("Two\n");

break;

case3:

printf("Three\n");

break;

case4:

printf("Four\n");

break;

case5:

printf("Five\n");

break;

case6:

printf("Six\n");

break;

}

}

Continue Statement in C

In C, the continue statement is used to skip the remaining statements of the current iteration of a loop and transfer control directly to the next iteration.

Notes: -

loop terminate नहीं करता, बस current iteration skip कर देता है।

#include stdio.h

int main ()

{

int i;

for (i=1; i<=10;i++)

{

if(i==2)

continue;

printf("%d\n",i);

}

}
